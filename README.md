# jhuannp.github.io

Portfólio de Jhuann: programação, pesquisa e ensino.

Site estático gerado a partir de um repositório privado. A biblioteca didática contém material
em rascunho preparado com apoio de IA; isso não comprova revisão completa nem domínio do conteúdo.
As páginas de disciplinas são notas de estudo, não material oficial das disciplinas.

Nesta versão estática, a correção dos exercícios roda no navegador e as respostas ficam nos
arquivos de `api-static/`.
