# Campos receptivos: contraste espacial e limites do modelo

Construção original: D=C−(L+R)/2; taxas R_ON=max(0,b+gD),R_OFF=max(0,b−gD). L,C,R são médias locais em unidades relativas, não medidas absolutas de luminância. b=10s⁻¹,g=10s⁻¹/unidade são parâmetros artificiais. Três amostras não representam a geometria circular de um campo real, a fototransdução, dinâmica, adaptação, ruído, circuitos sinápticos ou percepção.

Execute `python3 labs/campo-receptivo/field.py` e `python3 -m unittest discover -s labs/campo-receptivo -t .`. Int/Fraction, intensidades0..2,baseline/ganho0..100,sem dependências. Os números são racionais exatos para o modelo; taxa não é contagem de disparos registrada. Não existe processo de Poisson ou amostragem temporal aqui. Cores do SVG indicam apenas níveis relativos; valores numéricos são a referência,sem calibração fotométrica do monitor.
